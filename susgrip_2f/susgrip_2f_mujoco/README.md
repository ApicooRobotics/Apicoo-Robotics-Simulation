## SUSGRIP 2F Description (MJCF)

> Requires MuJoCo 2.2.2 or later.

### Overview

This package contains a simplified robot description (MJCF) of the 
[Smart 2-Finger Parallel Gripper](https://apicoorobotics.com/products-robotic-grippers/)
 developed by [Apioo Robotics](https://apicoorobotics.com/). 

<p float="left">
  <img src="susgrip_2f/susgrip_2f_mujoco/susgrip_2f.png" width="600px">
</p>

### Excute

```python
python susgrip_2f.py
```

```python
python susgrip_2f_invert.py
```
